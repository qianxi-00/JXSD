## 四、实测踩坑汇总（写代码前先看这 8 条）

这些都是**本地实测**得出的硬结论，官方文档没写清或写得容易误读：

1. **`retry_on` 对超时是精确类型匹配**：`RetryPolicy(retry_on=(TimeoutError,))`
   **不会**重试节点超时（只尝试 1 次）；要写 `(NodeTimeoutError,)` 或用默认 `RetryPolicy()`。
   虽然 `NodeTimeoutError` 在 Python 里是 `TimeoutError` 的子类。（`01_langgraph/11`）
2. **节点 `timeout=` 只支持异步节点**：同步节点上写 timeout 直接抛
   `ValueError: Node timeouts are only supported for async nodes ...`；
   且必须走异步入口 `asyncio.run(graph.ainvoke(...))`。（`01_langgraph/11`）
3. **默认 RetryPolicy 不重试 `ValueError` 这类业务异常**（实测 1 次即抛）——
   这是特性：参数错误重试没有意义。（`01_langgraph/11`）
4. **`add_edge(START, ["a","b"])` 与 `add_node_defaults` 在 langgraph 1.2.11 不存在**
   （官方最新文档才有）：前者实测 `TypeError: unhashable type: 'list'`。
   本地要并行扇出请用 Send。（`01_langgraph/10`）
5. **`Command` 只新增动态边**：如果节点同时有静态出边，`goto` 的目标和静态边的目标
   **都会执行**。（`01_langgraph/10`）
6. **漏传 `context` 时异常会穿透**：`runtime.context` 为 `None`，工具里访问属性抛
   `AttributeError`，而 ToolNode 默认对非 `ToolException` 直接 re-raise，运行中断
   （不是转成错误消息）。想转消息要挂 `ToolErrorMiddleware`。（`02_langchain/16`）
7. **deepagents 的 `write_todos` 自 v0.7 起 opt-in**：默认栈不含 TodoList，
   且 `TodoListMiddleware` 来自 **langchain** 包而非 deepagents。
   模式报错长这样：`Error: write_todos is not a valid tool, try one of [ls, read_file, ...]`。
   （`03_deepagents/14`）
8. **上下文卸载的实测形态**：100,002 字符的工具结果进历史时只剩 1,608 字符，
   形如 `Tool result too large, ... saved in the filesystem at this path: /large_tool_results/c1`，
   完整内容在 `result["files"]["/large_tool_results/c1"]`。（`03_deepagents/14`）
9. **本机网关无视 `max_tokens`**：设 `max_tokens=16` 请求长文，两次实测分别返回
   4,574 / 6,147 个输出 token 且 `finish_reason=stop` —— 参数被接受但不执行。
   控长度要靠提示词 + 自截断 + 监控 `finish_reason`，别假设参数一定生效。（`02_langchain/23`）
10. **图片内容块在本机不可用**：带 image 块的请求报 `OpenAIConnectionError: Connection error`
   （同一端点纯文本调用正常）。（`02_langchain/23`）
