关于本示例

本页面演示了 Jinja2 的另一个常见用法： 把公共部分（页头、导航、页脚）放在 base.html， 子模板只写 {% raw %}{% block content %}{% endraw %} 里的内容。

为什么要模板继承？

  1. 改一次导航栏，全站生效 —— 不用逐个文件改；
  2. 新人一眼看懂页面结构：只有 content 块是需要关心的；
  3. 避免复制粘贴导致的不一致（比如某个页面忘了加 viewport）。

模板 vs JSON 接口：什么时候用哪个？

场景返回什么原因
服务端渲染的传统网站、后台页面HTML 模板浏览器直接展示，SEO 友好
前后端分离的 SPA / 移动端JSON前端框架自己渲染，接口可复用
本课案的 FastAPI 示例JSON 为主现代后端常态：只做数据接口
