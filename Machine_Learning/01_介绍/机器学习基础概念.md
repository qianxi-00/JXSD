## 1. 什么是机器学习

### 1.1 一句话定义

**机器学习（Machine Learning, ML）是人工智能的一个分支，它让计算机系统能够从数据中学习并改进性能，而不需要被人明确地编程。**

关键词是最后半句：**无需被明确编程（without being explicitly programmed）**。传统程序里，"规则"是人写死的；机器学习里，"规则"是算法自己从数据里"学"出来的。

机器学习的目标是：**开发能够自动学习和改进的算法**。

### 1.2 与传统编程（明确编程）的区别

| 维度 | 传统编程 / 明确编程 | 机器学习 |
| --- | --- | --- |
| 输入 | **规则（程序逻辑）** + 数据 | **数据** + 答案（标签） |
| 输出 | 答案 | **规则（模型）** |
| 谁写规则 | 程序员手工编写 `if / else`、公式 | 算法从数据中自动拟合 |
| 面对的问题 | 规则**已知且可描述** | 规则**未知、难以显式描述** |
| 举例 | 计算个税：税率表 → 公式 | 判断邮件是不是垃圾邮件：给 1 万封已标注邮件 → 模型 |
| 维护方式 | 改需求改代码 | 改需求补数据、重训模型 |
| 表达能力瓶颈 | 规则复杂度随场景爆炸（"写不完的 if"） | 规则由数据驱动，可随数据扩展 |

**为什么有些问题必须用机器学习？** 因为它们属于"**我们知道答案长什么样，但说不清判断规则**"的问题：

- 人脸识别：你无法用 `if` 写出"这是张三"的规则，但你能轻松标出 1 万张照片是谁。
- 语音识别、机器翻译、推荐系统、垃圾邮件过滤、信用评分、医学影像判读……

反之，**规则明确的问题不要用机器学习**：算工资、算面积、排序、格式转换——用传统编程更快、更准、更可解释。

### 1.3 Tom Mitchell 的形式化定义（T / P / E）

Tom Mitchell 在 1997 年给出了被引用最多的形式化定义：

> 对于某类任务 **T** 和性能度量 **P**，如果一个程序在 **T** 上以 **P** 衡量的性能随着**经验 E** 而自我改善，我们就说这个程序从经验中学习了。

| 符号 | 名称 | 含义 | 垃圾邮件分类的例子 |
| --- | --- | --- | --- |
| **T** | Task 任务 | 要完成的事情 | 判断一封邮件是否为垃圾邮件 |
| **P** | Performance 性能度量 | 用什么指标衡量做得好不好 | 分类准确率 / 精确率 / 召回率 |
| **E** | Experience 经验 | 用来学习的数据（历史经验） | 1 万封已人工标注"垃圾/正常"的邮件 |

**这个定义的价值**：它强迫你在动手前想清三件事——**我要解决什么任务？用什么指标算成功？我手里有什么数据？** 很多项目失败，不是模型不行，而是 T、P、E 三者中至少有一个没想清楚（例如指标 P 选错：在不平衡数据上只看准确率）。

### 1.4 机器学习的三要素

| 要素 | 说明 | 对应 MIT 定义 |
| --- | --- | --- |
| **数据（Data）** | 模型的信息来源；数量、质量、代表性决定上限 | E |
| **模型（Model）** | 从输入到输出的假设函数族，如线性函数、决策树 | 解决 T 的工具 |
| **算法（Algorithm / 优化）** | 在假设空间里寻找最优参数的方法，如梯度下降 | 学习的过程 |

一句业内常说的话：**数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限。**

## 2. 机器学习分类

### 2.1 分类总表（按课案）

| 类型 | 特点 | 典型任务 | 代表算法 |
| --- | --- | --- | --- |
| **监督学习** | 有标签数据 | 分类、回归 | 逻辑回归、SVM、决策树、随机森林 |
| **无监督学习** | 无标签数据 | 聚类、降维 | K-Means、DBSCAN、PCA、t-SNE |
| **半监督学习** | 部分标签数据 | 分类、回归 | 标签传播、自编码器 |
| **强化学习** | 通过奖励学习 | 决策优化 | Q-learning、Policy Gradient |

### 2.2 逐类中文解释

#### （1）监督学习（Supervised Learning）

- **数据形态**：$(x_i, y_i)$ 成对出现，$y_i$ 是人工标注的"标准答案"（标签）。
- **学什么**：一个从输入 $x$ 到输出 $y$ 的映射函数 $f: x \mapsto y$，使 $f(x)$ 尽量接近真实的 $y$。
- **再细分**：
  - **分类（Classification）**：$y$ 是**离散类别**。如鸢尾花品种（3 类）、是否患病（2 类）。
  - **回归（Regression）**：$y$ 是**连续数值**。如房价、血糖指标、销量。
- **损失思路**：直接比较预测值与标签的差距（0-1 损失、交叉熵、均方误差）。
- **代表算法**：线性/逻辑回归、SVM、KNN、决策树、随机森林、梯度提升（XGBoost / LightGBM）、神经网络。
- **优点**：效果最好、目标明确、容易评估。**缺点**：标签昂贵（要人标注），且有标签数据往往稀缺。

#### （2）无监督学习（Unsupervised Learning）

- **数据形态**：只有 $x_i$，**没有标签**。
- **学什么**：数据内部的结构、模式、分布。
- **典型任务**：
  - **聚类（Clustering）**：把相似的样本分到一组（K-Means、DBSCAN、层次聚类）。
  - **降维（Dimensionality Reduction）**：用更少的维度保留主要信息，便于可视化与去噪（PCA、t-SNE、UMAP）。
  - 还有：异常检测、密度估计、关联规则挖掘。
- **代表算法**：K-Means、DBSCAN、PCA、t-SNE。
- **优点**：数据易得（不需要标注）。**缺点**：没有"标准答案"，结果好坏难评估，需要领域知识解释。

#### （3）半监督学习（Semi-Supervised Learning）

- **数据形态**：**少量有标签 + 大量无标签**数据。现实中非常常见（标注 100 张图容易，标注 100 万张图不可能）。
- **学什么**：用无标签数据帮助刻画数据分布，从而在标签稀少时仍能学好决策边界。
- **核心假设**：① 平滑假设——相近的样本大概率同类；② 流形假设——高维数据其实分布在一个低维流形上；③ 聚类假设——同一簇内样本倾向同类。
- **代表算法**：标签传播（Label Propagation / Label Spreading）、自训练（Self-training）、半监督 SVM（S3VM）、自编码器预训练、伪标签（Pseudo-labeling）。
- **优点**：大幅降低标注成本。**缺点**：若假设不成立，无标签数据会"带偏"模型（确认偏误）。

#### （4）强化学习（Reinforcement Learning, RL）

- **数据形态**：没有现成的数据集，而是**智能体（Agent）与环境（Environment）交互**产生的序列：状态 $s_t$ → 动作 $a_t$ → 奖励 $r_t$ → 新状态 $s_{t+1}$。
- **学什么**：一个**策略（Policy）** $\pi(a \mid s)$——在什么状态下该做什么动作，使**长期累计奖励**最大。
- **与监督学习的根本区别**：没有"正确答案"，只有**延迟的、稀疏的奖励信号**；且当前动作会改变未来的数据分布（探索与利用的权衡，Exploration vs Exploitation）。
- **代表算法**：Q-learning、SARSA、DQN、Policy Gradient、Actor-Critic、PPO。
- **优点**：能解决序贯决策问题（游戏、机器人控制、自动驾驶、推荐、调度）。**缺点**：样本效率低、训练不稳定、奖励函数设计困难。

> **补充：还有其他分类维度**
> - 按**学习方式**：批学习（Batch）vs 在线学习（Online）vs 增量学习。
> - 按**模型形式**：参数模型 vs 非参数模型；生成模型 vs 判别模型。
> - 按**输出结构**：多标签、多示例、结构化预测。
> - 按**是否与环境交互**：监督/无监督（离线静态数据）vs 强化学习（在线交互）。

### 2.3 常见误区

1. **"无监督学习一定比监督学习差"**——它们解决的是不同问题，没有可比性。
2. **"准确率越高模型越好"**——类别极不平衡时（99% 正常邮件），模型全预测"正常"也有 99% 准确率，但毫无用处。此时要看精确率、召回率、F1、AUC。
3. **"数据越多越好"**——低质量、有偏、有泄漏的数据越多越糟。**垃圾进，垃圾出（Garbage in, garbage out）**。

## 3. 频率派 vs 贝叶斯派

机器学习中概率建模有两大理论流派，它们在**参数的理解、估计方法和计算本质**上截然不同。理解这一区别，是深入掌握各类算法底层原理的钥匙。

### 3.0 统一的记号约定

把数据表示为一个矩阵：

$$
X = (x_1, x_2, \dots, x_N)^{T} \in \mathbb{R}^{N \times P}
$$

- $N$：样本数量（行数）
- $P$：每个样本的特征维度（列数）
- $x_i \in \mathbb{R}^{P}$：第 $i$ 个样本（矩阵的第 $i$ 行）

假设数据 $X$ 服从某个由参数 $\theta$ 决定的概率分布 $P(X \mid \theta)$。

> **注意**：这里的 $X$ 是**数据**（观测到的），$\theta$ 是**参数**（决定分布形状的未知量）。两大流派的分歧，全部集中在**"$\theta$ 到底是什么"**这一个问题上。

### 3.1 频率派（统计机器学习视角）

#### 核心假设

> **参数 $\theta$ 是一个未知的常量（fixed but unknown constant），数据 $X$ 是随机变量。**

也就是说：世界上存在一个唯一的、固定的真值 $\theta^{*}$，它不会变；我们之所以得到不同的数据，是因为**抽样是随机的**。目标就是**通过数据把这个固定的参数值估计出来**。

（频率派的名字来源于"概率 = 长期重复试验中的频率"这一解释。）

#### 核心方法：极大似然估计（Maximum Likelihood Estimation, MLE）

$$
\hat{\theta}_{MLE} = \arg\max_{\theta} P(X \mid \theta)
$$

其中 $P(X \mid \theta)$ 作为 $\theta$ 的函数时，称为**似然函数** $\mathcal{L}(\theta)$：

$$
\mathcal{L}(\theta) = P(X \mid \theta)
$$

> **大白话**：我们要找一个估计值 $\hat{\theta}$，这个值应该让"**已经看到的这批数据 $X$ 出现的概率**"最大。注意似然不是"$\theta$ 的概率"（频率派不认为 $\theta$ 有概率），而是"**给定 $\theta$ 时数据的概率**"。

#### i.i.d. 假设 → 连乘 → 取对数 → 连加

由于样本**独立同分布（i.i.d., independent and identically distributed）**：

$$
P(X \mid \theta) = \prod_{i=1}^{N} P(x_i \mid \theta)
$$

连乘有几个致命问题：① 数值上 $N$ 大时会**下溢为 0**；② 求导时乘积法则繁琐。因为 $\log$ 是单调递增函数（不改变极值点位置），我们取对数，把**连乘转为连加**：

$$
\ell(\theta) = \log \mathcal{L}(\theta) = \log P(X \mid \theta) = \sum_{i=1}^{N} \log P(x_i \mid \theta)
$$

$$
\hat{\theta}_{MLE} = \arg\max_{\theta} \ell(\theta) = \arg\max_{\theta} \sum_{i=1}^{N} \log P(x_i \mid \theta)
$$

> **为什么可以随便取对数？** 因为 $\arg\max$ 只关心"在哪个 $\theta$ 上取到最大"，而 $\log$ 单调递增不改变这个位置。这叫**对数似然（log-likelihood）**，是几乎所有机器学习损失函数的来源。

#### 计算本质：**优化问题**

频率派的参数估计最终**都可以转化为优化任务**，标准流程为：

1. **设计模型**：确定假设函数形式，例如 $h_\theta(x) = \theta^{T}x$、$h_\theta(x) = \sigma(\theta^{T}x)$。
2. **定义损失函数（Loss Function）**：通常取负对数似然 $J(\theta) = -\ell(\theta)$（最大化似然 = 最小化负对数似然）。例如：
   - 高斯噪声假设下的线性回归 → **均方误差 MSE**：$J(\theta) = \dfrac{1}{2N}\sum_{i=1}^{N}(y_i - \theta^{T}x_i)^2$
   - 伯努利假设下的二分类 → **交叉熵**：$J(\theta) = -\dfrac{1}{N}\sum_{i=1}^{N}\left[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\right]$
3. **用梯度下降算法求解最优参数**：

$$
\theta_{t+1} = \theta_t - \eta \, \nabla_{\theta} J(\theta_t)
$$

其中 $\eta$ 是**学习率（learning rate）**。若损失函数是凸的且可解析求解（如最小二乘的正规方程 $\hat{\theta} = (X^{T}X)^{-1}X^{T}y$），也可以直接求闭式解。

> **一句话总结频率派**：**把学习变成了"求函数极小值"**。这也是深度学习（反向传播 + SGD）的底层逻辑。

### 3.2 贝叶斯派（概率图模型视角）

#### 核心假设

> **参数 $\theta$ 本身是随机变量，服从一个先验分布 $P(\theta)$。目标是通过贝叶斯定理，结合数据把先验更新为后验分布 $P(\theta \mid X)$。**

也就是说：**不确定性不只来自数据，也来自我们对参数本身的无知**。$\theta$ 没有唯一真值，而是有一整个**分布**——分布越窄，说明我们越确定。

#### 核心公式：贝叶斯定理

$$
P(\theta \mid X) = \dfrac{P(X \mid \theta)\,P(\theta)}{P(X)}
$$

#### 各部分含义

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $P(\theta \mid X)$ | **后验分布**（Posterior） | 数据更新后参数的分布——看完数据后我们对 $\theta$ 的**更新信念** |
| $P(X \mid \theta)$ | **似然**（Likelihood） | 数据在参数下的概率——"如果参数是 $\theta$，看到这批数据的可能性有多大" |
| $P(\theta)$ | **先验分布**（Prior） | 参数的初始假设分布（基于经验/领域知识） |
| $P(X)$ | **证据 / 归一化项**（Evidence） | 与 $\theta$ 无关，是参数空间上的积分结果：$P(X) = \int_{\theta} P(X \mid \theta) P(\theta)\,\mathrm{d}\theta$，作用是让后验成为一个合法的概率分布（积分为 1） |

用一句口诀记住：**后验 ∝ 似然 × 先验**

$$
\underbrace{P(\theta \mid X)}_{\text{后验}} \;\propto\; \underbrace{P(X \mid \theta)}_{\text{似然}}\; \times\; \underbrace{P(\theta)}_{\text{先验}}
$$

> 归一化常数 $P(X)$ 常常**算不出来**（高维积分不可解），这正是贝叶斯方法计算昂贵的根源；实际中要么用**共轭先验**直接得到解析后验，要么用 **MCMC 采样 / 变分推断**近似。

#### 两类关键方法

##### （1）最大后验估计（MAP, Maximum A Posteriori）

$$
\hat{\theta}_{MAP} = \arg\max_{\theta} P(\theta \mid X) = \arg\max_{\theta} P(X \mid \theta) \cdot P(\theta)
$$

等价的（取对数后）：

$$
\hat{\theta}_{MAP} = \arg\max_{\theta}\left[\log P(X \mid \theta) + \log P(\theta)\right]
$$

它**仅取后验分布的众数（mode）作为参数的点估计**。

> **关键提醒**：MAP **并不是标准的贝叶斯方法**，它更接近 **MLE 的扩展——只是多乘了一个先验**（在目标函数里多加了一项 $\log P(\theta)$）。因为它最后仍然只输出一个点，丢掉了后验分布的全部形状信息。

**一个极重要的联系：正则化就是 MAP。**

| 频率派的正则化 | 对应的贝叶斯先验 |
| --- | --- |
| L2 正则（Ridge）：$J = \text{MSE} + \lambda\lVert\theta\rVert_2^2$ | 高斯先验 $\theta \sim \mathcal{N}(0, \sigma^2)$ |
| L1 正则（Lasso）：$J = \text{MSE} + \lambda\lVert\theta\rVert_1$ | 拉普拉斯先验（稀疏先验） |

也就是说，工程师眼中的"加个正则防过拟合"，在贝叶斯眼中就是"我认为参数应该接近 0，把这个信念写进了先验"。

##### （2）标准贝叶斯估计与预测

- **贝叶斯估计**：目标是求出**完整的后验分布** $P(\theta \mid X)$，而非单个点估计。这个分布能告诉我们：参数最可能是多少、有多大不确定性、置信区间多宽。
- **贝叶斯预测**：对新样本 $\tilde{x}$ 的预测分布为

$$
P(\tilde{x} \mid X) = \int_{\theta} P(\tilde{x} \mid \theta)\, P(\theta \mid X) \,\mathrm{d}\theta
$$

**核心是以参数 $\theta$ 为桥梁，将已知数据与新样本关联起来**：对所有可能的 $\theta$ 取值，先用 $P(\theta \mid X)$ 问"这个 $\theta$ 有多可信"，再用 $P(\tilde{x} \mid \theta)$ 问"如果真是这个 $\theta$，新样本长什么样"，最后**加权平均（积分）**。本质是对后验分布做**积分**。

#### 符号含义速查表

| 符号 | 含义 |
| --- | --- |
| $\tilde{x}$ | 我们想要预测的**新样本**（比如下一次掷硬币的结果） |
| $X$ | 我们已经观察到的**旧数据**（比如已经掷过的 10 次硬币结果） |
| $\theta$ | 模型的**参数**（比如硬币正面朝上的概率）。真实的 $\theta$ 我们不知道 |
| $P(\tilde{x} \mid X)$ | **预测分布**。在已知旧数据 $X$ 的条件下，新数据 $\tilde{x}$ 出现的概率。这是我们最终想要的东西 |
| $P(\tilde{x} \mid \theta)$ | **似然**。假如参数的真值是某个 $\theta$，那么新数据 $\tilde{x}$ 出现的概率。这通常是我们对数据生成过程的假设（比如伯努利分布） |
| $P(\theta \mid X)$ | **后验分布**。看完旧数据 $X$ 之后，我们对参数 $\theta$ 的更新信念。它是一个完整的分布，体现了 $\theta$ 所有可能取值的可信度 |
| $\int_{\theta}\cdots \mathrm{d}\theta$ | 对参数 $\theta$ 所有可能的值进行**积分**（$\theta$ 连续时）或**求和**（$\theta$ 离散时）。意思是"把所有情况都考虑进去" |

#### 完整例子：掷硬币

**场景**：一枚硬币，正面朝上的概率记为 $\theta$（未知）。我们已经掷了 $N = 10$ 次，记为旧数据 $X$，其中正面 $h = 7$ 次、反面 $N - h = 3$ 次。现在问：**下一次掷出正面（$\tilde{x} = 1$）的概率是多少？**

**① 似然**：单次抛掷服从伯努利分布，由 i.i.d. 得

$$
P(X \mid \theta) = \theta^{\,h}(1-\theta)^{\,N-h} = \theta^{7}(1-\theta)^{3}
$$

**② 先验**：用共轭先验 Beta 分布（因为 Beta 与伯努利共轭，后验仍是 Beta，可解析求解）

$$
P(\theta) = \mathrm{Beta}(\theta; \alpha, \beta) = \frac{\theta^{\alpha-1}(1-\theta)^{\beta-1}}{B(\alpha, \beta)}
$$

Beta 分布的均值是 $\dfrac{\alpha}{\alpha+\beta}$，可以理解为"先验中的等效试验中，正面 $\alpha$ 次、反面 $\beta$ 次"。

**③ 后验**（共轭性：乘起来后归一化，直接得到）

$$
P(\theta \mid X) = \mathrm{Beta}(\theta;\, \alpha + h,\; \beta + N - h)
$$

看这个式子：**数据只是把先验的两个超参数各加上了观测到的正/反次数**。这就是共轭先验的威力，也是贝叶斯方法"在线学习"的天然优势——旧后验可以直接当新先验继续用。

**④ 三种答案**（设先验 $\alpha = \beta = 2$，即温和地认为硬币大概公平）

| 方法 | 公式 | 数值 | 含义 |
| --- | --- | --- | --- |
| 频率派 MLE | $\hat{\theta}_{MLE} = \dfrac{h}{N}$ | $7/10 = \mathbf{0.700}$ | 只看数据，先验完全不参与 |
| 贝叶斯 MAP | $\hat{\theta}_{MAP} = \dfrac{\alpha + h - 1}{\alpha + \beta + N - 2}$ | $8/12 \approx \mathbf{0.667}$ | 点估计，被先验"拉"向 0.5 |
| 标准贝叶斯预测 | $P(\tilde{x}=1 \mid X) = \mathbb{E}[\theta \mid X] = \dfrac{\alpha + h}{\alpha + \beta + N}$ | $9/14 \approx \mathbf{0.643}$ | 对所有可能的 $\theta$ 加权平均，最"保守" |

**三个数值对比的解读**：

- **MLE = 0.700**：纯粹相信数据（10 次太少，容易过拟合）。
- **MAP ≈ 0.667**：在 MLE 上多乘了一个先验，把估计值向先验均值 0.5 的方向**收缩（shrinkage）**。注意：如果先验取均匀分布 $\mathrm{Beta}(1,1)$，则 MAP $= (1+7-1)/(1+1+10-2) = 7/10 = 0.700$，**与 MLE 完全相等**——这直观地证明"MAP 就是加了先验的 MLE"。
- **贝叶斯预测 ≈ 0.643**：不是找最可能的 $\theta$ 再预测，而是**把每个 $\theta$ 的可能性都考虑进去做积分**。因为 $\theta$ 的取值被后验分布加权，它比 MAP 更"往中间缩"，并且小样本时更稳健。
- **当 $N \to \infty$ 时，三者都会收敛到真实值**：数据的力量最终压过先验（先验只是"小样本时的拐杖"）。

### 3.3 两大流派对比表

| 维度 | 频率派（Frequentist） | 贝叶斯派（Bayesian） |
| --- | --- | --- |
| **参数观** | $\theta$ 是**未知常量**（fixed but unknown），存在唯一真值 | $\theta$ 是**随机变量**，服从先验分布 $P(\theta)$ |
| **数据观** | 数据 $X$ 是随机变量，反复抽样产生 | 数据 $X$ 是已实现的观测，一旦观测到就固定 |
| **目标** | 估计出那个唯一的真值 $\hat{\theta}$ | 求出**完整的后验分布** $P(\theta \mid X)$ |
| **计算本质** | **优化问题**——设计模型 → 定义损失 → 梯度下降求极值 | **积分问题**——对参数空间积分（$\int_\theta$），求归一化常数与预测分布 |
| **输出** | 一个**点估计**（+ 渐近标准误/置信区间） | 一个**分布**（完整的后验 + 预测分布），天然带不确定性 |
| **核心公式** | $\hat{\theta}_{MLE} = \arg\max_\theta \log P(X \mid \theta)$ | $P(\theta \mid X) = \dfrac{P(X \mid \theta)P(\theta)}{P(X)}$，$P(\tilde{x}\mid X)=\int_\theta P(\tilde{x}\mid\theta)P(\theta\mid X)\mathrm{d}\theta$ |
| **优点** | 计算简单可扩展；优化算法成熟（SGD/Adam）可做大模型大数据；大样本下有渐近理论保证（一致性、渐近正态、有效性）；不需要指定先验，更"客观" | 小样本下可引入领域知识；输出完整不确定性（对风险评估、主动学习极有价值）；支持在线/增量更新（后验→新先验）；预测分布而非单点 |
| **缺点** | 小样本下不确定性刻画不足；先验信息无法利用；正则化只是经验性的工程手段；对 $p \gg N$ 问题需额外处理 | 归一化常数 $P(X)$ 常常不可积；计算昂贵（MCMC / 变分推断）；先验选择带主观性，先验错了结论就错（**先验敏感**）；大规模数据上难以落地 |
| **代表算法** | MLE、最小二乘、逻辑回归、SVM、EM 算法、GMM、神经网络（点估计 + 反向传播） | 朴素贝叶斯、贝叶斯线性回归、高斯过程（GP）、LDA 主题模型、贝叶斯网络、贝叶斯神经网络、贝叶斯优化 |

### 3.4 怎么选？一段总结

- **"我要一个能用的预测函数，数据也不少"** → 频率派（优化路线）更划算。工业界 95% 的场景属于这一类。
- **"我数据很少，但我对参数有先验知识"** 或 **"我需要量化不确定性/给出置信区间"** 或 **"我要边来数据边更新"** → 贝叶斯派更合适。如 A/B 测试的贝叶斯分析、小样本医疗、推荐系统的 Thompson Sampling、超参数调优的贝叶斯优化。
- **两者不是敌人**：MAP 用先验给 MLE 加正则；频率派的大样本结论与贝叶斯后验在数据量大时趋于一致（Bernstein–von Mises 定理）；现代深度学习的很多技巧（权重衰减、Dropout、SWAG）都能从贝叶斯角度重新解释。
- **本课案的主线走的是频率派（优化）路线**：`sklearn` 中绝大多数估计器（`LogisticRegression`、`RandomForestClassifier`、`SGDRegressor`……）都是在最小化某个损失函数；`NaiveBayes` 系列则带明显的贝叶斯血统。

## 4. scikit-learn（sklearn）介绍

### 4.1 它是什么

**scikit-learn（sklearn）是 Python 最流行的机器学习库，提供了从数据预处理到模型训练的完整工具链。** 它建立在 NumPy / SciPy 之上，特点是：API 统一、文档优秀、算法齐全、面向中小规模数据（单机内存内）。

### 4.2 设计哲学

1. **一致的 API（最核心）**：所有模型都是"估计器（Estimator）"，都用 `fit` / `predict` / `transform` / `score`，**换模型通常只需要改一行 import 和一个类名**。
2. **组合优于继承**：`Pipeline` 把"预处理 + 模型"串成一条流水线；`ColumnTransformer` 对不同列做不同处理；`GridSearchCV` 把任意估计器加进搜索。
3. **`fit` 学参数，`transform` 用参数**：所有需要从数据学统计量的步骤（均值方差、PCA 方向、编码字典）都必须遵守这个分离，防止数据泄漏。
4. **不重复造轮子**：深度学习交给 PyTorch/TensorFlow，梯度提升的极致性能可用 XGBoost/LightGBM（本课案环境都已安装）。
5. **元信息可自省**：`get_params()` / `set_params()` 让模型可以被自动化搜索与复制（`clone`），这是 `GridSearchCV` 能工作的前提。

### 4.3 三类对象（后面脚本会反复用到）

| 类别 | 做什么 | 必须有 | 典型例子 |
| --- | --- | --- | --- |
| **Estimator（估计器）** | 从数据中学习，基类 | `fit(X, y=None)` | `RandomForestClassifier`、`KMeans` |
| **Transformer（转换器）** | 把数据 $X$ 变成新形态 $X'$ | `fit` + `transform` + `fit_transform` | `StandardScaler`、`PCA`、`OneHotEncoder` |
| **Predictor（预测器）** | 对新数据输出预测 | `predict`（分类器还有 `predict_proba`） | `LogisticRegression`、`DecisionTreeRegressor` |

> 关系：**Predictor ⊂ Estimator**；**Transformer ⊂ Estimator**。`ClassifierMixin` / `RegressorMixin` / `TransformerMixin` 只是给估计器加上 `score` / `fit_transform` 的快捷方法。

## 5. sklearn 标准工作流程

### 5.1 五步流程总览

| 步骤 | 做什么 | 关键 API | 常见坑 |
| --- | --- | --- | --- |
| **① 提取数据** | 拿到特征 `X` 与标签 `y` | `load_iris(return_X_y=True)` | 忘记区分 `X`（二维）和 `y`（一维） |
| **② 清洗与划分数据** | 处理缺失/异常 → **先划分训练/测试集** → 再标准化 | `train_test_split`、`StandardScaler` | **先标准化全量数据再划分 → 数据泄漏** |
| **③ 运行算法** | 在**训练集**上学习 | `model.fit(X_train, y_train)` | 用测试集 `fit` |
| **④ 得到结果** | 对**测试集**预测 / 转换 | `model.predict(X_test)`、`scaler.transform(X_test)` | 用 `fit_transform(X_test)` → 数据泄漏 |
| **⑤ 评估** | 用指标衡量泛化能力 | `accuracy_score`、`cross_val_score`、`confusion_matrix` | 只在训练集上评估 → 虚高 |

### 5.2 Estimator API 三件套

```python
model.fit(X_train, y_train)     # 学习：从训练数据中估计参数
model.predict(X_test)           # 预测：用学到的参数对新数据输出结果
model.score(X_test, y_test)     # 评估：返回该模型默认的评分（分类器 = 准确率，回归器 = R²）
```

**注意 `score` 的默认口径不同**：

| 对象 | `score` 返回什么 | 越大越好？ |
| --- | --- | --- |
| `ClassifierMixin`（分类器） | 平均准确率 accuracy | 是 |
| `RegressorMixin`（回归器） | 决定系数 $R^2$ | 是（1 为完美，0 为等同瞎猜均值，**可以为负**） |
| `ClusterMixin`（如 `KMeans`） | **负数**的簇内平方和（`-inertia`） | 是（因为取了负号，越接近 0 越好） |
| 纯 `Transformer`（如 `StandardScaler`） | 默认**没有** `score` 方法 | — |

> 所以生产代码里通常不依赖 `score`，而是显式调用 `sklearn.metrics` 里的指标函数，口径清晰可控。

### 5.3 `fit_transform` 与 `fit().transform()` 的区别

- `transform`：**只做转换**，用**已经学到的参数**把数据映射到新空间。
- `fit`：**只学参数**（`StandardScaler` 学均值 `mean_` 和标准差 `scale_`；`PCA` 学主成分方向）。
- `fit_transform`：**先 `fit` 再 `transform`**，等价于 `fit(X).transform(X)`（`TransformerMixin` 提供的语法糖，有些实现还会为性能做一步优化）。

```python
scaler = StandardScaler()
Z_train = scaler.fit_transform(X_train)     # 学训练集统计量 + 转换训练集  ✅ 正确
Z_test  = scaler.transform(X_test)          # 复用训练集统计量转换测试集    ✅ 正确
# Z_test = scaler.fit_transform(X_test)     # ❌ 错误：测试集统计量泄漏进了流程
```

**一句话记忆**：**`fit_transform` 只能用在训练集上；测试集永远只用 `transform`。**

### 5.4 为什么必须"先在训练集 `fit`，再 `transform` 测试集"？（数据泄漏）

**数据泄漏（Data Leakage）**：在训练过程中，模型"偷看"到了本应在预测时才可见的信息（尤其是**测试集的信息**）。

标准化时若对**全量数据**求均值方差，测试集的均值和方差就参与了训练：

```
❌ 错误做法：
X, y = load_iris(return_X_y=True)
X = StandardScaler().fit_transform(X)        # 用了全部数据（含未来的测试集）算均值方差
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

✅ 正确做法：
X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)   # 先划分
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)      # 只用训练集学统计量
X_test  = scaler.transform(X_test)           # 测试集复用训练集统计量
```

**危害**：① 评估结果**虚高**（乐观偏差），上线后性能大跌；② 划分不再独立，测试集不再是"没见过的新数据"。这是一种**隐蔽的作弊**——你在用未来信息预测未来。

**为什么标准化要放在划分之后（课案强调的点）**：

1. **统计量必须是"只从训练集学到"的**——否则泄漏。
2. **真实部署时的场景也是"用训练时的统计量处理新数据"**——训练/推理必须一致，否则分布对不上。
3. **注意 `train_test_split` 之后 `X_train` 与 `X_test` 的尺度不一致也没关系**——`transform` 会把它们映射到同一个坐标系（因为用的是同一套训练集统计量）。

> **测试集用 `transform` 之后，其均值不一定恰好为 0、标准差不一定恰好为 1**——这是**正常的、正确的**，因为它用的是训练集的均值方差。

### 5.5 关键函数的参数速查

#### `train_test_split(X, y, test_size=0.25, random_state=42, stratify=None, shuffle=True)`

| 参数 | 含义 | 实践建议 |
| --- | --- | --- |
| `test_size` | 测试集占比（0~1 的小数）或样本数（整数）。默认 0.25 | 数据少用 0.2~0.3；百万级用 0.01~0.05 即可 |
| `train_size` | 训练集占比；与 `test_size` 二者只需给一个 | 一般不写 |
| `random_state` | 随机种子。固定后**每次划分结果完全相同** | **必须固定**，否则实验不可复现 |
| `stratify` | 按该数组的类别比例分层抽样，通常写 `stratify=y` | **分类任务强烈建议加上**，尤其类别不平衡时 |
| `shuffle` | 划分前是否打乱顺序。默认 `True` | 时序数据要**小心**（见下） |

- **为什么分类要 `stratify=y`？** 保证训练集和测试集的**类别比例与原始数据一致**。否则样本少时测试集可能一个少数类样本都没有，评估结果完全不可信。
- **时序数据的坑**：股票、日志等有先后顺序的数据不能用默认的随机打乱（会用到"未来"预测"过去"）。应使用 `shuffle=False` 或 `TimeSeriesSplit`。

#### `StandardScaler(with_mean=True, with_std=True)`

把每个特征变成**均值 0、标准差 1**：$z = \dfrac{x - \mu}{\sigma}$

| 参数 | 默认 | 含义 | 什么时候改 |
| --- | --- | --- | --- |
| `with_mean` | `True` | 是否减去均值（中心化） | 稀疏矩阵必须设 `False`（减均值会破坏稀疏结构） |
| `with_std` | `True` | 是否除以标准差（缩放） | 某特征方差本身是常数量纲时可视情况关闭；一般保持默认 |
| `copy` | `True` | 是否复制数据而不原地修改 | 内存紧张可设 `False`（会改原数组，慎用） |

**学到的属性**（带下划线结尾，sklearn 约定：`fit` 之后才有）：`mean_`、`scale_`、`var_`、`n_features_in_`、`feature_names_in_`。

**为什么需要它？** ① 距离型算法（KNN、K-Means、SVM、PCA）会被量纲大的特征主导；② 梯度下降在特征尺度不一时收敛慢、易震荡；③ 正则化项对所有参数一视同仁，尺度不齐会导致惩罚不公平。**树模型（决策树、随机森林、XGBoost）对单调缩放不敏感，可以不标准化**。

#### `RandomForestClassifier(n_estimators=100, max_depth=None, random_state=None, n_jobs=None)`

| 参数 | 含义 | 调参直觉 |
| --- | --- | --- |
| `n_estimators` | 森林里树的数量 | 越大越稳、方差越小，但耗时线性增长，且收益递减。常用 100~1000 |
| `max_depth` | 单棵树最大深度，`None` 表示不限（长到叶纯） | 控制**过拟合**最直接的旋钮。小 → 欠拟合，大 → 过拟合 |
| `random_state` | 随机种子（同时控制 bootstrap 抽样与特征子集采样） | **固定以保证可复现** |
| `n_jobs` | 并行进程数，`None`=1，`-1`=用满所有 CPU | 大幅加速，但注意与 `random_state` 组合时的复现性（结果是确定的，只是并行） |
| `min_samples_leaf` / `min_samples_split` | 叶节点/分裂所需最小样本数 | 比 `max_depth` 更精细的防过拟合手段 |
| `max_features` | 每次分裂考虑的特征数（默认 `"sqrt"`） | 越小 → 树之间越"独立"，方差越低 |
| `oob_score` | 是否用袋外样本估计泛化误差 | 数据少时可用 `True` 免费拿到一个泛化估计 |
| `class_weight` | 类别权重，可设 `"balanced"` | 类别不平衡时的重要参数 |

> **随机森林为什么有效？** Bagging（自助采样 + 并行训练）+ 特征随机选择 → 单棵树的方差互相抵消；属于"**低偏差、高方差**的基学习器 + **降方差**的集成策略"。

## 7. 自检清单与常见坑

### 7.1 每次写完机器学习代码，问自己这 8 个问题

1. **有没有先划分数据、再做任何"从数据学统计量"的操作？**（标准化、填充缺失、编码、特征选择、PCA、SMOTE……全都必须在划分之后、且只在训练集上 `fit`）
2. **测试集有没有被用于任何形式的训练？**（包括调参！调参要用验证集或交叉验证，不能看测试集）
3. **随机过程是否都固定了 `random_state`？**
4. **分类任务是否加了 `stratify=y`？**
5. **评估指标是否匹配业务目标？**（不平衡分类别只看准确率；回归任务看 MAE/RMSE/R² 而非"准确率"）
6. **训练集和测试集的分数差距大吗？**（差距大 → 过拟合；两个都低 → 欠拟合）
7. **有没有用交叉验证而不是单次划分来估计性能？**（单次划分的方差可能很大）
8. **特征尺度是否与所用算法匹配？**（距离型/梯度型要标准化，树模型不必）

### 7.2 高频错误速查

| 错误 | 症状 | 正确做法 |
| --- | --- | --- |
| 先标准化再划分 | 测试分数虚高、上线掉点 | 先 `train_test_split`，再 `fit` 训练集、`transform` 测试集 |
| 测试集上用 `fit_transform` | 同上 | 测试集只用 `transform` |
| 用测试集调参 | 测试集不再中立，最终分数乐观 | 用 `cross_val_score` / `GridSearchCV` 在训练集上调 |
| 忘记 `random_state` | 每次结果都不一样，无法复现 | 所有随机过程固定 `random_state=42` |
| 分类不平衡时只看准确率 | 99% 准确率却毫无价值 | 看 `confusion_matrix`、`classification_report`、`roc_auc_score` |
| 训练集准确率当性能 | 严重过拟合却自我感觉良好 | 必须报告测试集分数，并与训练集对比 |
| 无脑标准化一切 | 树模型结果几乎无变化，白白增加耗时 | 树/提升类可跳过；SVM/KNN/PCA/线性模型必须做 |
| 用到 `squared=False`、`labels=` 这类旧参数 | 报 `TypeError`（新版本已移除） | 用新 API：`root_mean_squared_error`、`tick_labels=` |

> **本章一句话总结**：机器学习 = **用数据自动找规则**。它按"有没有标签 / 有没有奖励"分为监督、无监督、半监督、强化四类；在概率建模上分为**频率派（把学习变成优化问题）**与**贝叶斯派（把学习变成积分问题）**两大流派；而 `scikit-learn` 用统一的 Estimator API 把"**提取数据 → 清洗与划分 → fit → predict → 评估**"这一标准流程固定了下来——**先划分、再 fit、只用训练集学参数**，是这条流程里最不能违反的铁律。
