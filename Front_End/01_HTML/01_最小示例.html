一、网页是什么？

网页本质上是一份 HTML 文档，浏览器负责解析并渲染显示。 你右键选择「查看网页源代码」看到的那一堆尖括号，就是浏览器看到的原始输入； 你眼前花花绿绿的版面，是浏览器加工之后的结果。

用户看到的样子  ←→  HTML 源代码

二、上面那个最小示例的完整代码

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
    <h1>Hello</h1>
    <p>这是一段文字</p>
</body>
</html>

三、逐行拆解

代码 名称 作用
<!DOCTYPE html> 文档类型声明 告诉浏览器「请用 HTML5 标准模式渲染我」。必须放在文件第一行。
<html> 根元素 整个文档的「根」，除了 DOCTYPE 之外所有内容都包在它里面。
<head> 头部 放「给浏览器看的配置」：编码、标题、样式、脚本引用。不直接显示。
<meta charset="UTF-8"> 字符编码声明 指定用 UTF-8 解读字节，中文不乱码的关键。
<title> 页面标题 浏览器标签页上的文字，不显示在正文里。
<body> 主体 页面上所有「看得见」的内容都写在它里面。
<h1> 一级标题 最大号标题，h1 到 h6 逐级变小。
<p> 段落 一段文字，前后自动留白。

四、标签的书写规律

HTML 标签几乎都是「成对出现」的，格式是：

<标签名 属性="值">内容</标签名>
   ↑ 开始标签（开标签）        ↑ 结束标签（闭标签，多了一个斜杠 /）
小练习：把本文件里的 <h1>Hello</h1> 改成 <h1>你好，网页！</h1>，保存后刷新浏览器， 看看页面发生了什么变化。这就是「改源代码 → 网页跟着变」的第一次体验。
怎么自己看效果？
方式一：直接双击本文件（操作系统会用默认浏览器打开它）。
方式二：打开浏览器，按 Ctrl + O，选择本文件。
方式三：在文件管理器里把本文件拖进浏览器窗口。
