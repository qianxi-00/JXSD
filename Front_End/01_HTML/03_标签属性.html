HTML 标签属性演示

标签负责「这是什么」，属性负责「它是什么样的、它指向哪里」。 属性的书写格式固定为：属性名="值"，写在开始标签内部，多个属性之间用空格隔开。 

<a href="https://example.com" class="link" id="main">点击这里</a>
   └── 开始标签名
        └────────────── 三个属性，空格分隔 ──────────────┘  └─ 内容 ─┘ └ 结束标签 ┘

一、课案三大核心属性：href / class / id

1）href 链接地址（专用属性）

href 是 <a> 标签的专用属性——只有 <a> 这类标签才认它。 值可以是绝对 URL、相对路径、页面内锚点（#开头）或 mailto:。

2）class 类名（全局属性，可重复）

class 是「分类标签」。它的核心特征是 可以被重复使用： 页面上可以有 100 个元素都写 class="link"，它们会共享同一套样式。 一个元素也可以同时拥有多个 class，用空格分隔，例如 class="link big red"。

3）id 唯一标识（全局属性，必须唯一）

id 是元素的「身份证号」，在同一个页面里必须唯一。 它的主要用途有两个：① 用 #id 精确地给某一个元素上样式； ② 让 JavaScript 用 document.getElementById("id") 快速找到它 （这是下一章 DOM 操作的基础）；③ 页面内锚点跳转 href="#id"。

二、全局属性 vs 专用属性

类别 含义 例子
全局属性 几乎所有标签都能用 class、id、style、title、hidden、data-*
专用属性 只有特定标签才有意义 <a href>、<img src / alt>、<input type / placeholder>、<button disabled>

为什么要有这个区分：因为写属性时写错名字，浏览器不会报错，只会默默忽略它。 知道「这个属性是不是这个标签的」，能帮你快速排查「为什么我的样式/功能没生效」。

布尔属性：只要写了就算「真」

像 disabled、checked、hidden、required 这类属性，写不写值都行：<button disabled> 和 <button disabled="disabled"> 效果一样。 关键点：只要这个属性名出现了，就是「开启」；要「关闭」必须把整个属性删掉—— 写成 disabled="false" 依然是禁用（因为字符串 "false" 是真值），这是个经典坑。

四、data-* 自定义属性：给 JavaScript 留数据

有时候我们想在自己的标签上挂一点「业务数据」（比如商品 id、用户 id）， 但不想乱造属性名。HTML5 提供了 data-* 规范写法： 属性名必须 data- 开头，后面随便起。

  • 轻薄本 — ¥3999
  • 机械键盘 — ¥1299
  • 显示器 — ¥899

// JavaScript 读取 data-* 属性：用 dataset，把 data-xxx 写成 dataset.xxx（中划线转小驼峰）
const li = document.querySelector(".product");
console.log(li.dataset.id);      // "1001"
console.log(li.dataset.price);   // "3999"
console.log(li.dataset.name);    // "轻薄本"

五、易错点小结

  • 属性必须写在开始标签里，写在结束标签里无效。
  • 值建议始终加引号。不加引号在值里含空格时会被截断，例如 class=a b 实际只认了 a。
  • 属性名不区分大小写（HREF 和 href 一样）， 但习惯上全部小写；而属性值里 class/id 名是区分大小写的，别弄混。
  • 同一个标签里不能有两个同名属性，写了两个浏览器只认第一个。
  • 行内 style 优先级最高，会盖掉 <style> 和外部 CSS 里的同名规则—— 调试样式不生效时，先检查这里。
