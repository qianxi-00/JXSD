## 1. 网页是什么

**网页本质是一份 HTML 文档，浏览器负责渲染显示。**

```
用户看到的样子  ←→  HTML源代码
```

- 你在浏览器里看到的文字、图片、按钮，全部来自服务器发过来的**一个纯文本文件**（就是 `.html`）。
- 浏览器拿到这份文本后做两件事：**解析**（把文本变成内存里的 DOM 树）→ **渲染**（把树画成像素）。
- 所以「右键 → 查看网页源代码」看到的，就是浏览器拿到的原始输入。这是理解前端一切问题的起点：
  **页面不对，先去看源代码对不对。**

## 2. HTML 最小示例

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
    <h1>Hello</h1>
    <p>这是一段文字</p>
</body>
</html>
```

### 骨架各部分的职责

| 部分 | 名称 | 职责 |
|---|---|---|
| `<!DOCTYPE html>` | 文档类型声明 | 告诉浏览器用 HTML5 标准模式渲染。必须是文件第一行 |
| `<html>` | 根元素 | 除 DOCTYPE 外的所有内容都包在里面；`lang="zh-CN"` 声明语言 |
| `<head>` | 头部 | 放「给浏览器看的配置」：编码、标题、样式、脚本引用。**不直接显示** |
| `<meta charset="UTF-8">` | 编码声明 | 中文不乱码的关键，**必须写** |
| `<title>` | 页面标题 | 显示在浏览器标签页 / 收藏夹 / 搜索结果标题上 |
| `<body>` | 主体 | 页面上**所有看得见的内容**都写在这里 |

### 标签的书写规律

```
<标签名 属性="值">内容</标签名>
   ↑ 开始标签              ↑ 结束标签（多一个斜杠）
```

- 绝大多数标签**成对出现**。
- 少数标签没有内容，叫**空元素**，写成单个标签即可：`<br>`、`<hr>`、`<img>`、`<input>`、`<meta>`、`<link>`。
- 标签可以**嵌套**，但不能交叉：
  - ✅ `<div><p>文字</p></div>`
  - ❌ `<div><p>文字</div></p>`（浏览器会替你"猜"一个结构，结果往往不是你想要的）

## 3. HTML 常用标签

课案的 8 类核心标签：

| 标签 | 含义 | 说明 |
|---|---|---|
| `<div>` | 区块 | 主要结构容器，块级，**本身没有任何默认外观** |
| `<span>` | 行内文本 | 包裹小段文字，行内，**本身没有任何默认外观** |
| `<h1>`~`<h6>` | 标题 | h1 最大，h6 最小；不只是字号，还带**语义** |
| `<p>` | 段落 | 文本段落，块级，前后自动留白 |
| `<a href="...">` | 链接 | 跳转页面 |
| `<img src="...">` | 图片 | 嵌入图片，空元素 |
| `<ul><li>` | 列表 | 无序列表 |
| `<table>` | 表格 | 表格数据 |

### 块级元素 vs 行内元素（最重要的分类）

| | 块级 block | 行内 inline |
|---|---|---|
| 占位方式 | **独占一行**，宽度默认撑满父容器 | 和文字排在同一行，宽高由内容决定 |
| 能否设置 width/height | 能 | **不能**（设了也无效，除非改成 `display:inline-block`） |
| 典型标签 | `div` `p` `h1~h6` `ul` `ol` `li` `table` `section` `header` `footer` `form` | `span` `a` `img` `b` `strong` `i` `em` `input` `button` `label` |
| 能否互相嵌套 | 块级可包容内元素 | 行内**不应**包含块级元素 |

> **为什么必须分清？** 因为「为什么我的 `width` 不生效」这个问题，
> 99% 的原因是：你给一个 `span`（行内元素）设了宽度。

### 补充常用标签

| 标签 | 作用 |
|---|---|
| `<br>` | 强制换行（空元素） |
| `<hr>` | 水平分割线（空元素） |
| `<ol><li>` | 有序列表（1. 2. 3.） |
| `<strong>` / `<b>` | 加粗（`strong` 带"重要"语义，读屏会重读） |
| `<em>` / `<i>` | 斜体 |
| `<pre>` | 保留原始空格与换行，常用来展示代码 |
| `<code>` | 行内代码 |
| `<header>` `<nav>` `<main>` `<section>` `<article>` `<aside>` `<footer>` | **语义化标签**，功能等同 div，但名字自带含义，利于 SEO 与无障碍 |
| `<form>` `<input>` `<button>` `<select>` `<textarea>` | 表单类标签 |
| `<audio>` `<video>` | 音视频 |
| `<iframe>` | 内嵌另一个网页 |

## 4. HTML 标签属性

属性写在**开始标签**里，格式 `属性名="值"`，多个属性用空格隔开。

```html
<a href="https://example.com" class="link" id="main">点击这里</a>
```

### 课案三大核心属性

| 属性 | 含义 | 关键特征 | 主要用途 |
|---|---|---|---|
| `href` | 链接地址 | `<a>` 的**专用属性** | 跳转：外部 URL / 相对路径 / `#锚点` / `mailto:` |
| `class` | 类名 | **可重复**，一个元素可有多个（空格分隔） | 复用样式，CSS 用 `.类名` 选中 |
| `id` | 唯一标识 | **全页必须唯一** | JS 用 `getElementById` 精确抓取、页面内锚点跳转、CSS 用 `#id` 选中 |

> **一句话判断用哪个：** "这个元素可能不止一个" → `class`；"全页只有一个且 JS 要单独操作" → `id`。

### 全局属性 vs 专用属性

- **全局属性**：几乎所有标签都能用 —— `class` `id` `style` `title` `hidden` `lang` `data-*`
- **专用属性**：只有特定标签才有意义 —— `<a href>`、`<img src/alt>`、`<input type/placeholder>`、`<button disabled>`

> 写错属性名时浏览器**不会报错**，只会默默忽略。所以"样式/功能没生效"时，先检查属性名写对没有。

### 常见属性速查

| 属性 | 适用标签 | 作用 |
|---|---|---|
| `href` | `<a>` `<link>` | 目标地址 |
| `src` | `<img>` `<script>` `<audio>` `<video>` `<iframe>` | 资源地址 |
| `alt` | `<img>` | 图片加载失败时的替代文字 + 无障碍读屏文本（**不可省**） |
| `width` / `height` | `<img>` `<video>` `<canvas>` | 尺寸（只写 width 会等比缩放） |
| `class` / `id` | 几乎所有 | 类名 / 唯一标识 |
| `style` | 几乎所有 | **行内样式**，优先级最高，但不利于复用 |
| `title` | 几乎所有 | 鼠标悬停时的小气泡提示 |
| `target` | `<a>` `<form>` | `_blank` = 新标签页打开 |
| `type` | `<input>` `<button>` `<script>` | 类型区分 |
| `placeholder` | `<input>` `<textarea>` | 灰色提示文字 |
| `disabled` `checked` `required` `hidden` | 表单类 | **布尔属性** |
| `data-*` | 几乎所有 | 自定义数据，JS 用 `element.dataset.xxx` 读取 |

### 布尔属性的坑

`disabled`、`checked`、`hidden` 这类属性，**只要属性名出现了就是"开启"**：

- `<button disabled>` → 禁用 ✅
- `<button disabled="disabled">` → 禁用 ✅
- `<button disabled="false">` → **依然禁用** ❌（因为字符串 `"false"` 是真值）

要关闭必须**把整个属性删掉**。

### 属性书写易错点

1. 属性必须写在**开始标签**里，写在结束标签里无效。
2. 值**建议始终加引号**：`class=a b` 会被解析成 `class="a"` 加上一个名叫 `b` 的布尔属性。
3. 属性**名**不区分大小写（`HREF` = `href`），但属性**值**里的 class/id 名**区分大小写**。
4. 同一标签里**不能有两个同名属性**，写了两个只认第一个。
5. 行内 `style` 优先级最高，会盖掉 `<style>` 和外部 CSS —— 调试样式不生效先查这里。

## 5. 理解网页结构：嵌套关系

### 嵌套示例

```html
<div class="article">
    <h1>文章标题</h1>
    <div class="content">
        <p>第一段<span class="highlight">关键词</span>内容</p>
    </div>
</div>
```

### 树形结构

```
div.article
├── h1
└── div.content
    └── p
        └── span.highlight
```

### 关系术语

| 术语 | 含义 |
|---|---|
| **父节点** parent | 直接包住我的那一层 |
| **子节点** child | 我直接包住的那些 |
| **兄弟节点** sibling | 和我同一个父节点的其他节点 |
| **祖先** ancestor | 父、祖父、曾祖父……所有上层 |
| **后代** descendant | 子、孙、曾孙……所有下层 |
| **根节点** root | 最顶层，永远是 `<html>` |

> 这套术语直接对应 CSS 选择器：`.article p`（后代）vs `.article > p`（仅直接子元素），
> 以及 JS 的 `parentNode` / `children` / `nextElementSibling`。

### 缩进

浏览器会把标签之间的换行和空格**压缩成一个空格**，所以缩进**不影响渲染**，
但它决定了代码能不能维护。规范：**每进一层缩进 2 或 4 个空格**。

### 嵌套禁忌（浏览器会静默改写你的结构）

| 错误写法 | 后果 |
|---|---|
| `<p>` 里放 `<div>` | 浏览器提前闭合 `<p>`，层级被改写成三个兄弟节点，CSS 选择器全部失效 |
| 行内元素里放块级元素（如 `<span><div></div></span>`） | 渲染结果异常，布局崩溃 |
| `<ul>` 的直接子元素不是 `<li>` | 结构非法 |
| `<tr>` 里不是 `<td>/<th>` | 表格渲染错乱 |
| 标签交叉 `<div><p></div></p>` | 浏览器替你猜结构，结果不确定 |

**共同点：这些错误都不会报错。** 所以写 HTML 时要靠开发者工具去核对真实 DOM。

## 6. 开发者工具使用

| 操作 | 看到什么 | 什么时候用 |
|---|---|---|
| 右键 → **查看网页源代码**（Ctrl+U） | 服务器发来的**原始 HTML 文本** | 确认文件本身写对了没有 |
| 右键 → **检查**（F12） | 浏览器内存里**当前真实的 DOM 树**（已纠错、已含 JS 动态修改） | 排查"为什么样式/脚本没生效" |
| Elements 面板 → 悬停标签 | 页面上对应区域高亮 | **找元素最快的办法** |
| Elements → Styles 子面板 | 该元素最终生效的所有 CSS 规则（被划掉的表示被覆盖） | **调样式必看** |
| Elements → 双击属性值修改 | 页面立刻变化，刷新即还原 | 试验样式，不用担心改坏 |
| Console 面板 | 可执行任意 JS | 快速验证想法 |

**"查看源代码"和"检查"看到的不是同一个东西** —— 这是新手最大的认知盲区。
如果 JS 动态改了 DOM，前者看不到，后者能看到。

## 7. 重点回顾

- HTML 是**结构**，用标签描述"这里是什么"。
- 一份标准文档 = `<!DOCTYPE html>` + `<html>` + `<head>`（配置）+ `<body>`（内容）。
- 标签分**块级**（独占一行）和**行内**（排在文字里），这决定了 `width/height` 是否生效。
- 属性写在开始标签里，`class` 可重复、`id` 必须唯一。
- HTML 文档在浏览器内存里是一棵 **DOM 树**，父子/兄弟关系是 CSS 和 JS 的共同基础。
- HTML 的**容错性极强**：写错了不报错，只是结果不是你想要的 —— 所以必须靠**开发者工具**核对。
