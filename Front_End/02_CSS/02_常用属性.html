CSS 常用属性演示

课案把「常用属性」分成三组：文字样式、背景与边框、尺寸。 下面每一组都把课案原文的例子原样跑了一遍，并补充了实际工作中最常用的其他属性。 每个属性都写明了「它管什么 / 可以填什么值 / 为什么要这么写」。

一、文字样式

1）课案原文示例

这是一段居中显示的 16 号灰色 Arial 文字

p {
    color: #333;            /* 文字颜色 */
    font-size: 16px;        /* 字号 */
    font-family: Arial;     /* 字体族 */
    text-align: center;     /* 水平居中 */
}

2）文字属性速查

属性作用常用值
color文字颜色颜色关键字 / #hex / rgb() / rgba()
font-size字号16px / 1.2rem / 120%
font-family字体族（可写多个，从左往右找，逗号分隔）"Microsoft YaHei", Arial, sans-serif
font-weight字重（粗细）400=normal、700=bold
text-align水平对齐（作用于块级元素内部的行内内容）left / center / right / justify
line-height行高（行与行之间的距离）无单位数字（字号的倍数，如 1.75）最推荐
text-decoration装饰线none / underline / line-through
letter-spacing字间距2px
text-shadow文字阴影2px 2px 4px rgba(0,0,0,.4)
text-transform大小写转换uppercase / lowercase / capitalize

3）font-weight 字重

font-weight: 100 —— 极细

font-weight: 400 —— 正常（等于 normal）

font-weight: 700 —— 加粗（等于 bold）

font-weight: 900 —— 极粗

注意：具体能显示几种粗细，取决于你的系统里装没装这个字体的对应字重。中文字体通常只有 400 和 700 两档。

4）text-align 水平对齐

text-align: left —— 左对齐（默认）

text-align: center —— 居中

text-align: right —— 右对齐

text-align: justify —— 两端对齐。文字会被拉伸到左右两边都贴齐， 中文长段落用它看起来更整齐，但最后一行通常还是会保持自然宽度。

常见的「居中不生效」问题：text-align: center 只能让块级元素内部的行内内容水平居中。 想让一个「盒子本身」水平居中，要用 margin: 0 auto;， 或者用后面要学的 display:flex; justify-content:center;。

5）装饰、阴影、间距

下划线 underline

删除线 line-through

链接去掉下划线（text-decoration: none，做导航菜单必备）

文字阴影 text-shadow

字间距 letter-spacing: 8px

行高 line-height: 2.4 —— 第一行
行高 line-height: 2.4 —— 第二行
行高 line-height: 2.4 —— 第三行

text-transform: uppercase makes this lowercase text SHOUT

.wide  { letter-spacing: 8px; }
.tall  { line-height: 2.4; }            /* 无单位 = 字号的倍数，最推荐 */
.upper { text-transform: uppercase; }

二、尺寸

1）课案原文示例

宽 200px × 高 100px
.box {
    width: 200px;
    height: 100px;
    background-color: #ddd;
    border: 1px solid #999;
}

2）尺寸单位

单位含义特点
px像素绝对单位，所见即所得，最常用
%百分比相对父容器的同名尺寸（宽度相对父宽、高度相对父高）
vw / vh视口宽/高的 1%100vw = 整个窗口宽度；做满屏 banner 常用
rem根元素（html）字号的倍数改一个根字号就能整站缩放，适合做响应式
em当前元素字号的倍数会层层相乘，容易算错，新手慎用
auto自动块级元素宽度默认 auto = 撑满父容器

3）几种宽度的实际效果

固定宽度 width: 200px：

200px 固定

百分比 width: 60%（随父容器变化，把浏览器窗口拉窄看看）：

父容器的 60%

视口单位 width: 30vw（窗口宽度的 30%）：

30vw

最大宽度 max-width: 420px（宽度自适应但不超过上限）：

max-width: 420px
重要提醒：默认情况下 width 指的是内容区的宽度， 元素最终占的总宽度 = width + padding + border（padding 和 border 会"往外撑"）。 这正是盒子模型要讲的内容。想让 width 包含 padding 和 border， 就设置 box-sizing: border-box;——这是现代 CSS 的第一条必备规则。

三、背景与边框

1）课案原文示例

有灰色背景、黑色边框、内边距和外边距的盒子
div {
    background-color: #f0f0f0;
    border: 1px solid black;
    padding: 10px;
    margin: 20px;
}

2）背景属性

background-color: #3498db（纯色）
background-color: rgba(231, 76, 60, .45)（半透明，能看到底下的灰）
background: linear-gradient(135deg, #667eea, #764ba2)（渐变，无需图片文件）
background-image + size + repeat + position（这里用渐变模拟"背景图"，仅作展示）
属性作用常用值
background-color背景色任意颜色值 / transparent
background-image背景图url("img/bg.png") 或 linear-gradient(...)
background-size背景图尺寸cover（铺满并裁切）/ contain（完整显示留白）/ 100% 100%
background-repeat是否平铺repeat / no-repeat
background-position背景图位置center / top left / 50% 50%
background上面全部属性的简写background: #eee url("a.png") no-repeat center / cover;
为什么推荐渐变而不是背景图？渐变是浏览器实时算出来的，零请求、零流量、任意分辨率都不糊。 做按钮、卡片头图、占位色块时优先考虑渐变。

3）边框属性

border: 2px solid #e74c3c（实线）
border: 2px dashed #3498db（虚线）
border: 3px dotted #27ae60（点线）
四边分别设置 border-top / right / bottom / left（四色边框）
border-radius: 16px（圆角）
50%
box-shadow: 0 4px 12px rgba(0,0,0,.25)（盒子阴影，做卡片必备）
/* border 简写顺序：宽度 样式 颜色，三者顺序可换但建议固定 */
border: 1px solid black;

/* 只要下边框（做分割线常用） */
border-bottom: 1px solid #e1e4e8;

/* 圆角：50% 变正圆 */
border-radius: 8px;

/* box-shadow: 水平偏移 垂直偏移 模糊半径 颜色 */
box-shadow: 0 4px 12px rgba(0, 0, 0, .25);
/* 内阴影加 inset： */
box-shadow: inset 0 0 8px rgba(0, 0, 0, .2);

四、颜色怎么写

写法示例说明
颜色关键字color: red只有 140 多个预设名，够用但不精确
6 位十六进制color: #3498db最常用：#RRGGBB，每两位 00~FF
3 位十六进制color: #f39每两位相同才能简写，#f39 = #ff3399
rgb()color: rgb(231,76,60)十进制 0~255
rgba()color: rgba(231,76,60,.35)第四个参数是透明度 0~1，做半透明必用
hsl()color: hsl(145,63%,42%)色相/饱和度/亮度，调同色系深浅最方便
#3498db   rgba(52,152,219,.3)   linear-gradient(90deg,#ff9a9e,#fad0c4)
取色技巧：按 F12 → 在 Styles 面板里点任意颜色的小方块，会弹出取色器， 可以可视化调整并实时复制出 hex / rgb / hsl 各种写法。不需要装任何工具。
