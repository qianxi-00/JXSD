外部 CSS 文件示例

本页面的所有样式都来自 css/style.css——一个独立的外部样式表文件。

一、课案原文写法

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>外部CSS示例</title> <link rel="stylesheet" href="styles.css"> </head> <body> <h1>引用外部样式文件</h1> <p>外部CSS文件styles.css中定义了样式</p> </body> </html>

配套的 styles.css：

h1 { color: green; } p { font-size: 18px; }

本项目把它落成了更接近真实项目的结构：HTML 放根目录，CSS 放进 css/ 子目录，这样文件一多也不会乱：

05_外部样式/ ├── index.html ← HTML 结构 └── css/ └── style.css ← CSS 样式

对应的引入写法就变成了：

<link rel="stylesheet" href="css/style.css">

二、为什么外部样式是「推荐」做法

对比项行内 style<style> 标签外部 .css 文件
作用范围 单个元素 单个页面 所有引用它的页面
能否复用 ❌ 完全不能 ⚠️ 只能复制粘贴 ✅ 一处修改，处处生效
浏览器缓存 ❌ 无（每次都随 HTML 传输） ❌ 无 ✅ 会被缓存，第二次打开不再下载
HTML 可读性 ❌ 结构里混满样式 ⚠️ 页面头部越来越长 ✅ HTML 只剩结构，干净
适合场景 临时调试 / 邮件 HTML 单文件 Demo / 本页独有样式 真实项目标准做法
「关注点分离」是前端工程化的第一原则： HTML 只管结构、CSS 只管样式、JS 只管行为。 三者分开，才能让不同的人同时改不同的文件而不打架， 也才能让浏览器把三份文件分别缓存起来，加快加载速度。

三、路径怎么写（新手最容易在这里出错）

写法名称含义结果
css/style.css 相对路径 当前 HTML 文件所在目录下的 css 子目录 ✅ 推荐，可随意搬迁
./css/style.css 相对路径（显式） ./ 就是「当前目录」，和上一条等价 ✅ 可以，但没必要
../css/style.css 相对路径（上一级） ../ 是「回到上一级目录」 ✅ 子页面引用公共样式时常用
/css/style.css 根路径 网站根目录开始。**用 file:// 直接打开 HTML 时会失效** ⚠️ 只在部署到服务器后有效
F:\x\style.css 绝对路径 本机完整路径 ❌ 换台电脑立刻失效
样式完全不生效时，按这个顺序排查： ① F12 → Network 面板看 style.css 是不是 404（红色）； ② 看路径有没有写错（大小写敏感！Style.css ≠ style.css 在某些系统上）； ③ 看 rel="stylesheet" 有没有漏； ④ 确认 HTML 和 css 文件夹的相对位置没被改动。

四、<link> 还是 @import？

在 CSS 内部也可以用 @import 引入另一个 CSS 文件：

/* 写在 style.css 的第一行 */ @import url("reset.css"); @import url("theme.css");
<link>@import
加载时机和 HTML 解析并行下载必须等外层 CSS 下载并解析完，才知道要下载它 → 串行，更慢
能否用媒体查询✅ media="..."✅ 也可以，但支持的语法更少
兼容性所有浏览器老 IE 不支持
结论优先用 <link>；@import 只用在少数需要"样式内聚"的场景（如打包工具生成的入口文件）。

五、style.css 里到底写了什么

打开同目录下的 css/style.css 可以看到完整的、带详细中文注释的样式代码。 它按下面的顺序组织（这也是真实项目推荐的书写顺序）：

  1. 全局重置（box-sizing / margin / padding 归零）
  2. CSS 变量（把主色调、圆角、间距集中定义，一处改全局变）
  3. 基础排版（body 字体、行高、链接颜色）
  4. 布局容器（.container / .page-header）
  5. 组件（.card / .data-table / .callout / .btn）
  6. 响应式（@media 媒体查询，窄屏适配）
CSS 变量（自定义属性）小示例：
:root { --primary: #2563eb; /* 定义变量 */ --radius: 10px; } .btn { background: var(--primary); /* 使用变量 */ border-radius: var(--radius); }
改一个 --primary，所有用到它的按钮、链接、边框颜色一起变。 这是做「主题色切换」最省事的办法。

六、动手验证

  1. 打开 css/style.css，把 --primary 的值从 #2563eb 改成 #e11d48（红色），保存，回到浏览器刷新（Ctrl+F5 强制刷新）。
  2. 观察：本页的标题渐变、按钮、卡片左边框、链接颜色是不是同时变了？
  3. 再新建一个 about.html，只需要写 <link rel="stylesheet" href="css/style.css"> 就能立刻拥有同一套外观 —— 这就是外部样式表的威力。
