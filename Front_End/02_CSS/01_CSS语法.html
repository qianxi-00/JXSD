红色的 24 像素标题（就是课案的 CSS 语法示例）

上面这行字之所以是红色、24 像素，完全是因为 <head> 里那段 h1 { color: red; font-size: 24px; }。删掉它，标题就会变回默认的黑色大字。 这就是 CSS 的全部意义：把「长什么样」从「是什么」里剥离出来。

一、CSS 是什么

CSS（Cascading Style Sheets，层叠样式表）用来控制网页的外观和布局。

技术负责类比
HTML内容结构 —— 这里是什么房子的砖墙、房间划分
CSS样式表现 —— 它长什么样刷墙、贴壁纸、摆家具
JavaScript行为交互 —— 它能干什么水电、开关、电梯

为什么要分开？因为一个页面可能有 100 个同样的"卡片"，样式只写一次就能全部生效； 改主题色也只改一个地方。如果把样式写死在 HTML 里，改一次要改 100 处。

二、一条 CSS 规则的解剖

h1 {
    color: red;
    font-size: 24px;
}
 ↑        ↑    ↑
 选择器    属性  值
    └──── 声明 ────┘（以分号结尾）
 └──────── 一条规则 ────────┘（用花括号包起来）
组成部分本例作用
选择器 selectorh1给「谁」上样式
属性 propertycolor、font-size改「什么」
值 valuered、24px改成「多少」
声明 declarationcolor: red;「属性: 值;」构成一条声明
三个新手常见语法错误： ① 忘了分号 color: red font-size: 24px;（后面那条会被整条丢弃）； ② 用了等号 color = red;（CSS 用冒号）； ③ 忘了花括号或分号漏在括号外面。 CSS 出错时不会报错、不会提示，只是那一条不生效 —— 所以 F12 的 Styles 面板是你唯一的朋友。

三、把 CSS 用到 HTML 上的三种方式

方式 1：行内样式（写在标签的 style 属性里）

我是行内样式：background 和 color 直接写在标签上 

<p style="color: red; font-size: 20px;">文字</p>

优点：最直接，改哪个元素就写哪个元素，优先级最高。
缺点：无法复用、无法统一修改、HTML 和样式混在一起难维护。
什么时候用：只调一个元素、临时试验、或者邮件 HTML 这种必须内联的场景。

方式 2：<style> 标签（内部样式表）

本页面用的就是这种方式——所有规则都写在 <head> 的 <style> 里。

<head>
    <style>
        h1 { color: blue; }
        .highlight { background: yellow; }
    </style>
</head>

优点：一个页面内可复用，写好选择器就能批量控制。
缺点：只能作用于当前这一个 HTML 文件；多个页面要重复粘贴。

方式 3：外部样式表（推荐）

把 CSS 单独写成一个 .css 文件，用 <link> 引进来。 完整可运行示例见本目录下的 05_外部样式/index.html + 05_外部样式/css/style.css。 

<link rel="stylesheet" href="css/style.css">

优点：一个 CSS 文件可以被成百上千个页面共用；浏览器会缓存它，第二次打开更快； HTML 文件干净，只剩结构。这是真实项目的标准做法。

优先级（谁说了算）：行内样式 > <style> / 外部 CSS。 但更准确的规则是「看选择器的权重」： !important > 行内 style > id 选择器(100) > 类/伪类选择器(10) > 标签选择器(1)。 权重相同时，后写的覆盖先写的（这就是"层叠"）。 结论：不要把行内样式当成"万能覆盖"，它只会让样式越来越乱。

六、关于「层叠」（Cascading）

CSS 名字里的 C 就是 Cascading（层叠）。当多条规则同时命中一个元素时，按这个顺序裁决：

  1. 来源与重要性：带 !important 的胜出（尽量别用）。
  2. 选择器权重： 行内 style(1000) > id(100) > 类/伪类/属性(10) > 标签/伪元素(1) > 通配(0)。 多个选择器权重相加，例如 .card h2 = 10 + 1 = 11。
  3. 书写顺序：权重相同时，后写的赢。

本页顶部的 h1 { color: red; } 权重只有 1，但因为页面上没有别的规则跟它抢， 所以它稳定生效。如果你在它后面再加一条 h1 { color: green; }，标题会变成绿色。

调试口诀：样式不生效 → ① 按 F12 看 Styles 面板里这条规则有没有被划掉； ② 看是不是被行内 style 覆盖了；③ 看选择器是不是写错了（比如把 .card 写成了 card）。
