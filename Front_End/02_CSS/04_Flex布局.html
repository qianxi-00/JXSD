CSS Flexbox 弹性布局

Flexbox（弹性盒子）是目前最主流的 CSS 布局方式，专门解决「一堆元素怎么排」的问题。 它的一句话原理是：给父容器设置 display: flex;， 它所有的直接子元素就自动变成"弹性项目"，按父容器设定的规则自动排列。 在 Flexbox 出现之前，让一个盒子垂直居中需要各种"奇技淫巧"；现在只需要两行。

一、课案原文示例（完整复现）

1
2
3
<div class="container">
    <div class="box">1</div>
    <div class="box">2</div>
    <div class="box">3</div>
</div>

<style>
.container {
    display: flex;              /* ① 让子元素变成弹性项目 */
    justify-content: center;    /* ② 水平方向：居中 */
    align-items: center;        /* ③ 垂直方向：居中 */
    gap: 10px;                  /* ④ 三个方块之间间隔 10px */
    height: 100px;              /* ⑤ 给容器高度，垂直居中有意义 */
    background-color: #eee;
}
.box {
    width: 60px;
    height: 60px;
    background-color: #3498db;
    color: white;
    display: flex;              /* 小方块自己也是容器，用来居中数字 */
    justify-content: center;
    align-items: center;
}
</style>

效果说明（课案原文）：

  • justify-content: center：子元素水平居中排列。
  • align-items: center：子元素垂直居中排列。
  • gap: 10px：三个蓝色方块之间间隔 10px。
把上面容器里的 display: flex; 删掉试试（用 F12 在 Elements 里取消勾选）， 三个方块会立刻变成「上下叠放的整行块」，因为 <div> 默认是块级元素。 这就是 Flex 最直观的价值。

二、理解 Flex 的关键：两根轴

Flex 布局里所有的属性，都是在回答两个问题： 「沿哪根轴排？」和「在这根轴上怎么对齐？」

1
2
3
概念默认方向谁控制方向谁负责这根轴上的对齐
主轴 main axis 水平向右（→） flex-direction justify-content
交叉轴 cross axis 垂直向下（↓） 由主轴方向决定（与主轴垂直） align-items / align-content
最容易搞混的地方：justify-content 管的是主轴， align-items 管的是交叉轴。
默认（flex-direction: row）时主轴是水平的，所以： justify-content = 水平对齐，align-items = 垂直对齐。
但一旦设成 flex-direction: column，主轴变成垂直的， 这两个属性的作用就完全颠倒了：justify-content 变成垂直，align-items 变成水平。
所以不要死记"水平/垂直"，要记"主轴/交叉轴"。

四、课案表格逐条讲解

1）justify-content —— 主轴（默认水平）对齐

值效果一句话记忆
flex-start所有元素靠左排列（默认值）挤在起点
center所有元素居中排列挤在中间
flex-end所有元素靠右排列挤在终点
space-between两端贴边，中间均分「导航栏左 logo 右菜单」就用它
space-around每项左右各留一半间距两端间距是中间的一半
space-evenly所有间距完全相等（含两端）最"均匀"

2）align-items —— 交叉轴（默认垂直）对齐

值效果
stretch所有元素靠顶对齐？不——是拉伸填满交叉轴（默认值）。所以子元素不写 height 时会被拉满容器高度
flex-start所有元素靠顶对齐
center所有元素垂直居中
flex-end所有元素靠底对齐
baseline按文字的基线对齐（做「图标 + 文字」行内对齐很有用）
注意 stretch 是默认值，这也是为什么「我在 flex 里给子元素设百分比高度没生效」—— 它被拉伸了。想让子元素自己决定高度，先设 align-items: flex-start;。

3）flex-direction —— 决定主轴方向

值主轴方向justify-content 管的是align-items 管的是
row（默认）水平，从左到右水平垂直
row-reverse水平，从右到左水平（方向反了）垂直
column垂直，从上到下垂直水平
column-reverse垂直，从下到上垂直（方向反了）水平

4）flex-wrap —— 放不下怎么办

值效果
nowrap（默认）不换行，子元素被压缩挤在一行里（可能变形）
wrap放不下就换到下一行
wrap-reverse换行，但行的顺序反过来（第一行在最下面）

配合 align-content 可以控制多行之间在交叉轴上的分布 （注意：只有换了行、且容器有剩余高度时才有效果）。

五、写在子元素上的属性（弹性项目属性）

属性作用
flex-grow「还有剩余空间时，我要不要分一点？」0=不分（默认），1=分。数值是比例
flex-shrink「空间不够时，我要不要被压缩？」1=可以缩（默认），0=不许缩
flex-basis分配空间前的「基准尺寸」，写 200px 或 auto（默认，看 width）
flex上面三个的简写：flex: grow shrink basis
align-self单独覆盖父容器的 align-items，只影响自己
order改变排列顺序（数字越小越靠前，默认都是 0），不改 HTML 结构
/* 最常用的三种写法 */
.item-a { flex: 1; }        /* = 1 1 0%   ：等分剩余空间（做等宽列） */
.item-b { flex: auto; }     /* = 1 1 auto ：按内容大小分配并伸展 */
.item-c { flex: none; }     /* = 0 0 auto ：固定大小，不伸不缩（做侧边栏） */

/* 三栏布局：左右固定 150px，中间自适应铺满 */
.layout { display: flex; gap: 12px; }
.side   { flex: 0 0 150px; }   /* 不伸不缩，固定 150px */
.main   { flex: 1; }           /* 吃掉剩下的全部空间 */

六、重点回顾 & 常见坑

  • Flex 属性写在父容器上（display / direction / justify / align / wrap / gap）， 子元素自动成为弹性项目。
  • 记"主轴/交叉轴"，不要记"水平/垂直"：justify-content 管主轴， align-items 管交叉轴；flex-direction: column 时两者作用互换。
  • align-items 默认是 stretch（拉伸），这是"高度不受控"的最常见原因。
  • flex: 1 是等分剩余空间；flex: 0 0 150px 是固定宽度侧边栏。
  • gap 是给子元素之间留间距的最佳方式，比给每个子元素写 margin 干净得多 （而且不会在两端多出间距）。
常见坑：
  1. flex 只对直接子元素生效。孙子元素不受影响——要么给中间那层也设 display:flex， 要么把属性设在正确的层级上。
  2. flex 容器的子元素，其 float / vertical-align 会失效。
  3. flex 容器子元素的 margin: auto 有奇效：例如 margin-left: auto; 可以把某个项目单独推到最右边 （比 justify-content: space-between 更灵活）。
  4. 绝对定位（position: absolute）的子元素不参与 flex 布局。
