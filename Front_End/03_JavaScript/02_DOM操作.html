JavaScript DOM 操作

JS 之所以能让网页"动起来"，靠的就是 DOM。 浏览器把 HTML 文档解析成内存里的一棵对象树，每个标签都是树上的一个对象， 每个对象都有属性和方法。JS 拿到这些对象，就能读它们的内容、改它们的样子、 加新的节点、删旧的节点。

DOM 操作的核心口诀（课案原文）：获取元素 → 修改元素。 不管多复杂的交互，拆开来永远都是这两步。 难点从来不是"改"（改就那几个属性和方法），而是"怎么准确地拿到那个元素"。

一、课案原文示例（完整复现）

课案原文的 HTML：

<h1 id="title">原始标题</h1>
<button id="btn1">点我修改标题</button>
<button id="btn2">点我变红色</button>
<button id="btn3">点我变大</button>

课案原文的 JS：

let title = document.getElementById("title");
let btn1 = document.getElementById("btn1");
let btn2 = document.getElementById("btn2");
let btn3 = document.getElementById("btn3");

// 点击后修改文字
btn1.onclick = function() {
    title.textContent = "标题被修改了！";
};

// 点击后变红色
btn2.onclick = function() {
    title.style.color = "red";
};

// 点击后字体变大
btn3.onclick = function() {
    title.style.fontSize = "40px";
};

步骤代码说明
① 获取元素 document.getElementById("title") 按 id 精确拿到那一个元素对象
② 修改元素 title.textContent = "..." 改文字

最容易踩的坑：CSS 属性名在 JS 里要改成"小驼峰"。
CSS 的 font-size → JS 的 style.fontSize
CSS 的 background-color → JS 的 style.backgroundColor
写成 style.font-size 会被当成减法运算而报错或静默失效。

二、获取元素：常用 DOM 操作方法（课案表格）

方法说明返回
document.getElementById("id")通过 id 获取元素单个元素 或 null
document.querySelector(".class")通过 CSS 选择器获取第一个匹配元素单个元素 或 null
document.querySelectorAll(".class")通过选择器获取所有匹配元素NodeList（类数组，可用 forEach）
document.getElementsByClassName("c")按类名获取（老 API）HTMLCollection（动态集合，没有 forEach）
document.getElementsByTagName("p")按标签名获取（老 API）HTMLCollection
element.closest(".card")从自己开始向上找最近的祖先单个元素 或 null

三、修改内容：textContent 与 innerHTML

属性说明安全性
element.textContent 获取/设置纯文本内容。HTML 标签会被当成普通文字显示出来 ✅ 安全
element.innerHTML 获取/设置 HTML 内容。字符串里的标签会被浏览器解析并渲染 ⚠️ 有 XSS 风险
element.innerText 类似 textContent，但会受 CSS 影响（隐藏元素的文字拿不到） ✅
element.value 表单元素（input / textarea / select）的值，注意不是 textContent ✅

四、修改样式：style 与 classList

方式 1：直接改行内样式 element.style.xxx

一次只能改一个属性，而且会写在元素的 style 属性上（行内样式优先级最高， 会覆盖外部 CSS，很难维护）。 

// CSS 属性名 → JS 用小驼峰
box.style.color = "red";
box.style.fontSize = "40px";           // font-size  → fontSize
box.style.backgroundColor = "#eee";    // background-color → backgroundColor
box.style.borderRadius = "8px";
// 也可以用 cssText 一次性写多条（会覆盖原有的所有行内样式）
box.style.cssText = "color:red; font-size:40px;";

方式 2：切换 class element.classList（推荐）

把样式的定义留在 CSS 文件里，JS 只负责"换一个类名"。 这是推荐做法：样式和逻辑分离，而且一次可以切换一整套样式。 

box.classList.add("active");        // 加一个类
box.classList.remove("active");     // 删一个类
box.classList.toggle("active");     // 有就删、没有就加（做开关最好用）
box.classList.contains("active");   // 判断有没有 → true / false
box.classList.replace("old", "new");// 替换

五、修改属性：getAttribute / setAttribute / dataset

const link = document.querySelector("a");

// 读写 HTML 属性
link.getAttribute("href");                       // 读取
link.setAttribute("href", "https://python.org"); // 设置
link.setAttribute("target", "_blank");
link.removeAttribute("target");                  // 删除
link.hasAttribute("target");                     // 判断存在

// 有一些属性会被"特殊对待"，可以直接点出来：
link.href = "https://python.org";   // 等价于 setAttribute("href", ...)，但更常用
input.value = "hello";              // 表单值
checkbox.checked = true;            // 勾选状态
img.src = "a.png";

// data-* 自定义属性用 dataset 读写（中划线转小驼峰）
// HTML: <div data-user-id="1001" data-role="admin">
const div = document.querySelector("div");
div.dataset.userId;                 // "1001"  （data-user-id → userId）
div.dataset.role;                   // "admin"
div.dataset.userId = "1002";        // 写回去，页面上会变成 data-user-id="1002"

六、增删元素（动态生成内容）

这是真实项目里用得最多的一组操作：数据一变，就动态生成/删除 DOM 节点。

// ① 创建元素
const li = document.createElement("li");     // 创建标签
li.textContent = "新的一条";                  // 填内容
li.className = "todo-item";                  // 加 class
li.dataset.id = "1001";                      // 加 data-* 属性

// ② 插入到页面上（这一步千万别忘，否则元素只存在于内存里，页面上看不到）
list.appendChild(li);          // 插到父元素内部的最后面
list.prepend(li);              // 插到父元素内部的最前面
list.insertBefore(li, ref);    // 插到 ref 的前面
ref.before(li);                // 插到 ref 前面（新 API）
ref.after(li);                 // 插到 ref 后面（新 API）

// ③ 删除
li.remove();                   // 删自己（推荐）
list.removeChild(li);          // 让父元素删子元素（老写法）

// ④ 清空一个容器的全部内容
list.innerHTML = "";           // 常用
// 或者：list.replaceChildren();  // 新 API，更语义化

// ⑤ 克隆已有节点
const clone = li.cloneNode(true);   // true = 连子孙一起克隆
性能提示：在循环里反复 appendChild 会触发多次页面重排，很慢。 正确做法是先用 document.createDocumentFragment() 或先在内存里拼好 innerHTML，最后一次性插入。

    八、重点回顾

    • DOM = 内存里的对象树。JS 不能直接改 HTML 文本，只能改 DOM 对象。
    • 核心口诀：获取元素 → 修改元素。
    • 获取：优先 querySelector / querySelectorAll（支持任意 CSS 选择器）。
    • 改内容：textContent（纯文本、安全）vs innerHTML（解析 HTML、有 XSS 风险）。
    • 改样式：CSS 属性名要转小驼峰（font-size → fontSize）； 优先用 classList 换 class，而不是堆 style。
    • 改属性：getAttribute / setAttribute； data-* 用 dataset 读写，自动做中划线↔小驼峰转换。
    • 增删：createElement → appendChild/append； element.remove() 删除。
    • 新创建的节点必须插入到文档里才会显示，只 createElement 是看不到的。
    • 拿元素之前先确认它存在，否则会拿到 null，再操作就报 Cannot read properties of null。
