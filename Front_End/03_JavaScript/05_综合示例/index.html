1课案原文：三者结合的完整示例

课案给出了三个文件，拼在一起就是一个能点的页面。请仔细看每个文件负责什么。

HTML（结构）
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>外部JS示例</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
<h1 id="title">点击次数：0</h1>
<button id="btn">点我</button>
<script src="app.js"></script>
</body>
</html>
CSS（样式）：styles.css
#title {
    color: #333;
    font-size: 24px;
}
JavaScript（交互）：app.js
let count = 0;
let btn = document.getElementById("btn");
let title = document.getElementById("title");

btn.onclick = function() {
    count++;
    title.textContent = "点击次数：" + count;
};
三者的分工，一句话记住：
HTML 说「这里有一个 id 叫 title 的标题、一个 id 叫 btn 的按钮」——只描述结构。
CSS 说「#title 这个元素长成什么样」——只看选择器，不关心内容。
JS 说「找到 btn，当它被点击时，把 title 的文字改成新的计数」——靠 id 把两者连起来。

2进阶实践一：待办清单（数据驱动视图）

这是真实项目里最常见的一类需求：一个列表，能增、能删、能标记完成。 它的实现思想叫「数据驱动视图」：

数据（数组） ──render()──▶ 页面（DOM） ◀──用户操作── 改数据

只维护一份数据，任何变化后都重新渲染一次 —— 这正是 React / Vue 的核心思想， 用原生 JS 也能体会一遍。

    这个清单用到了哪些知识点？（点开看）
    • DOM 操作：createElement / appendChild / remove() / innerHTML = "" 清空容器。
    • 事件处理：addEventListener； keydown 判断 event.key === "Enter"。
    • 事件委托：监听器只绑在 <ul> 上， 靠 event.target.closest("[data-action]") 判断点了哪个按钮 —— 所以每次重新渲染出来的新元素也自动生效。
    • 数组方法：push / filter / find / forEach。
    • classList：用 toggle("done") 切换完成状态的样式。
    • localStorage：把数据存到浏览器本地，刷新页面不丢。
    • CSS：Flexbox 做左右布局，text-decoration: line-through 做删除线。

    3进阶实践二：表单校验（阻止默认提交）

    表单是网页与用户交互最重要的入口。这一节演示完整的表单处理流程： 实时校验 → 提交前总校验 → 阻止页面刷新 → 模拟提交。

    最容易忘的一行：event.preventDefault()。 表单的默认行为是「把数据提交到 action 指定的地址，然后刷新整个页面」。 不阻止它，你写的所有 JS 状态都会丢失，用户会看到页面闪一下什么都没发生。

    4重点回顾

    HTML —— 定义网页结构

    • 标签 + 属性描述「这里是什么」
    • class 可重复，id 必须唯一
    • 文档在浏览器里是一棵 DOM 树

    CSS —— 控制网页样式

    • 盒子模型：content → padding → border → margin
    • Flexbox：弹性盒子，轻松对齐
    • 用 CSS 变量统一管理配色，可一键换主题

    JavaScript —— 实现网页交互

    • DOM 操作：用 JS 动态修改网页内容
    • 事件处理：让网页响应用户操作
    • 事件委托：一个监听器管一堆动态元素

    把这三件事合起来，你就能做出一个真正可用的网页。 下一步（见 ../../05_前端框架生态/README.md）是了解 React / Vue 这些框架如何把「数据驱动视图」这件事做到极致。
